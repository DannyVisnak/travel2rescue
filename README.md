# travel2rescue.de

Static [Astro 5](https://astro.build) website for **Travel2Rescue e.V.** — German-registered nonprofit rescuing street dogs on Lombok, Indonesia.

- **Live**: <https://travel2rescue.de>
- **CMS**: <https://travel2rescue.de/keystatic/>

## Quickstart

```bash
npm install
npm run dev      # → http://localhost:4321
```

| Script | What it does |
|---|---|
| `npm run dev` | Astro dev server with HMR |
| `npm run build` | Static + Vercel SSR bundle into `dist/` |
| `npm run preview` | Serve the built site locally |
| `npm run check` | `astro check` — TypeScript + template validation |
| `npm run og` | Regenerate `public/og-image.png` from `scripts/generate-og.mjs` |

## Stack

- **Astro 5** (`trailingSlash: 'always'`, `build.format: 'directory'`)
- **Tailwind CSS v4** via `@tailwindcss/vite` — no PostCSS config
- **Keystatic CMS** (`@keystatic/core` + `@keystatic/astro`) on the live site, local filesystem in dev
- **Resend** for transactional mail (contact + adoption forms)
- **Vercel** for hosting + serverless functions
- **TypeScript** with strict checks via `astro check`

## Key conventions

### Image fields are bare filenames

Keystatic's `fields.image({ publicPath: '/images/' })` stores **only the filename** in JSON (e.g. `IMG_0991.jpeg`) and the reader returns it bare — it does **not** prepend `publicPath`. Always wrap in `img()` from `src/lib/img.ts` before rendering:

```ts
import { img } from '@/lib/img';
<img src={img(entry.image, '/images/fallback.jpg')} />
```

`img()` is idempotent — paths already starting with `/` or `http` pass through.

### CMS reads need fallbacks

`reader.singletons.X.read()` returns `null` if the JSON file doesn't exist. Every page already has its original copy inline as a `??` fallback, so a missing/empty field renders identically to before.

### Multi-line strings in JSON use `\n`

`Lines.astro` renders `\n` → `<br/>`. Use it for headings/paragraphs Eileen can edit.

### Accent headings split

Headings with a colored accent word are split into `…Title` + `…TitleAccent` (or similar) and recomposed in the template, so the design stays consistent while both halves are editable.

### Tailwind v4 quirk

Never `@apply` a custom component class inside another custom class — it triggers an "unknown utility" build error. Inline the utilities instead.

The `--color-amber-*` tokens have been re-assigned to the brand accent color; `text-amber-500`, `bg-amber-500`, etc. resolve to whatever the brand currently is (currently sage green on `main`; pink on `claude/integration-pink`).

## Environment variables (Vercel)

| Variable | Required for | Notes |
|---|---|---|
| `KEYSTATIC_GITHUB_CLIENT_ID` | CMS admin | From the GitHub App settings page |
| `KEYSTATIC_GITHUB_CLIENT_SECRET` | CMS admin | Generated under "Client secrets" |
| `PUBLIC_KEYSTATIC_GITHUB_APP_SLUG` | CMS admin | The App's URL slug |
| `KEYSTATIC_SECRET` | CMS admin | Session-cookie signing secret, ≥32 chars |
| `RESEND_API_KEY` | Forms | From <https://resend.com> |
| `RESEND_FROM` | Forms (optional) | Default: `Travel2Rescue <kontakt@travel2rescue.de>` |
| `RESEND_TO` | Forms (optional) | Default: `travel2rescue@gmail.com` |
| `PUBLIC_PLAUSIBLE_DOMAIN` | Analytics (optional) | Set to enable the Plausible script in `<head>` |
| `PUBLIC_PLAUSIBLE_SRC` | Analytics (optional) | Override script URL for self-hosted Plausible |

The Keystatic GitHub App is **not** an OAuth App — see `CLAUDE.md` for the setup details and the "Expire user authorization tokens" toggle that's required for refresh tokens.

## Forms

Both `ContactForm` and the 39-question adoption form POST to internal API routes (`/api/contact`, `/api/adoption`) that send via Resend.

- The API content-negotiates: JS clients (sending `Accept: application/json`) get JSON; native form submits (no JS) get a 303 redirect to `/danke/?typ=…` on success or back to the page with `?error=1` on failure.
- Anti-bot: honeypot field `botcheck` is hidden via `tabindex="-1"` + `autocomplete="off"`. Any value present silently short-circuits to "ok" without sending mail.

## Add a new page

1. Create `src/pages/xyz.astro`
2. Wrap in `<BaseLayout title="…" description="…">`
3. (Optional) Add a Keystatic singleton in `keystatic.config.ts` and seed `content/pages/xyz.json` with the current copy as defaults
4. Read from it with `await reader.singletons.xyz.read()` and `?? fallback` every field

## Deploy

Push to `main` → Vercel auto-builds in ~30s. Preview branches deploy to their own `*.vercel.app` URL.

## Common gotchas

- **Broken images** → forgot to wrap in `img()`. Check `src/lib/img.ts` docstring.
- **Route collision warning** at build (`/api/keystatic/[...params]`) — expected; our override beats the auto-injected one.
- **`fields.image` field stuck "Failed to fetch" in admin** — usually a filename with weird chars (trailing space, etc.). Rename, update JSON references.
- **CSRF 403 on Keystatic refresh-token** — `security.allowedDomains` in `astro.config.mjs` must include `travel2rescue.de`. Already configured.
